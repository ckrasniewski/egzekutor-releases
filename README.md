# Egzekutor — instalator

Gotowe wersje aplikacji dla Windows.

## Instalacja

1. Otwórz https://github.com/ckrasniewski/egzekutor-releases/releases/latest
2. W sekcji „Assets” kliknij plik `egzekutor-X.Y.Z-setup.exe`.
3. Jeśli przeglądarka ostrzeże, że plik nie jest często pobierany, wybierz „Zachowaj”.
4. Uruchom pobrany plik. Gdy pojawi się niebieskie okno „System Windows ochronił ten komputer”,
   kliknij „Więcej informacji”, a potem „Uruchom mimo to”.
5. Aplikacja zainstaluje się sama (bez pytania o hasło administratora), doda skrót na pulpicie
   i uruchomi się.

Kolejne wersje aplikacja pobiera sama — wystarczy kliknąć „Zaktualizuj teraz”.
